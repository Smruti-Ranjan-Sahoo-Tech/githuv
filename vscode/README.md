# GithuV for VS Code

Bring your GitHub project collaboration into VS Code. GithuV gives your team a shared sidebar for discussing a repository, coordinating work with tasks, and keeping conversations connected to the code you are working on.

## What you can do

- **Chat with your team** in a live, repository-specific room.
- **Coordinate tasks** from the same sidebar, with task lists and details available alongside your code.
- **See repository context** for the GitHub project open in your workspace.
- **Work with code from chat** by copying suggestions, inserting text, or applying changes to workspace files.
- **Keep a record of conversations** in your workspace.

## Get started

1. Install **GithuV** from the VS Code Marketplace.
2. Open a workspace cloned from a GitHub repository.
3. Select the GithuV icon in the Activity Bar, or run **GithuV: Open Chat** from the Command Palette.
4. Sign in with GitHub and start collaborating.

Chat and repository collaboration are available to the repository owner and collaborators. GithuV connects to the GithuV services, and GitHub sign-in is used to identify you and check repository access.
